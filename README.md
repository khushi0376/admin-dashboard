 2. Title of the Experiment

Title:To develop an Admin Dashboard using CSS Grid layout with dynamic theme switching.

3. Defined Approach

The objective of this experiment is to design and implement a modern Admin Dashboard interface using core web technologies.

The approach followed in this project is as described below:

1. HTML Structure

    Created a clean and semantic HTML layout consisting of a header, sidebar, and main content area.
    Used sections such as `<header>`, `<aside>`, and `<section>` to improve readability and structure.

2. CSS Grid Layout

   Implemented CSS Grid to divide the dashboard into two main columns: a navigation sidebar and a content area.
   Used grid properties to evenly distribute dashboard cards and maintain consistent spacing.

3. UI Design and Shapes

   Applied rounded corners, soft borders, gradients, and shadow effects to closely match the given dashboard design.
    Ensured visual depth and a modern appearance using box-shadow and border-radius properties.

4. Dynamic Theme Switching

    Used CSS variables to define color themes.
    Implemented JavaScript to toggle between Dark Mode and Light Mode by adding and removing a class on the `<body>` element.

5. Responsiveness

    Added media queries to ensure the dashboard layout adapts properly on smaller screen sizes.
    Sidebar and cards automatically stack for mobile view.

This approach ensures the dashboard is visually appealing, responsive, and easy to extend for future features.



Result: A fully functional Admin Dashboard UI with CSS Grid layout and dynamic theme switching was successfully implemented.
